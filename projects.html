još projekata koji pripadaju ovdje

mecanum line follower

Arduino Mega, encoder driveri, IR senzori, PID regulacija i mecanum kotači. Projekt koji je vrlo dobro objasnio zašto rezervni motor driver nije loša ideja.

retro konzola

Raspberry Pi + vlastito 3D printano kućište. Jer kupiti gotovo kućište očito nije bilo dovoljno zanimljivo.

kućni server

Raspberry Pi / OMV / Samba i kućni storage. Manje spektakularno od robota, ali puno korisnije kad treba naći file koji je nestao prije šest mjeseci.
