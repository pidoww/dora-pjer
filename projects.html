🏠 Homelab / Raspberry Pi 5 / NAS / VPN

Srce homelaba je Raspberry Pi 5 s 8 GB RAM-a. Projekt je krenuo kao kućni NAS, ali se s vremenom pretvorio u mali self-hosted server: storage, SMB file sharing, udaljeni pristup preko VPN-a, HTTPS administracija, automatizacija i nadzor događaja.

platforma: Raspberry Pi 5, 8 GB
NAS sloj: OpenMediaVault
file sharing: Samba / SMB
diskovi: oko 1.8 TB + 916 GB
shareovi: BLACK + BLUE
remote access: PiVPN / OpenVPN
VPN transport: custom UDP port
admin: OMV web UI preko HTTPS-a
automatizacija: systemd + hook skripte
obavijesti: SMTP / e-mail event logovi

arhitektura: što je javno, a što ostaje iza VPN-a

internet
   │
   ▼
router / javna IP
   │
   │  NAT + port-forward samo za VPN servis
   ▼
Raspberry Pi 5
   │
   ├── OpenVPN / PiVPN
   │      │
   │      └── šifrirani tunel prema kućnom LAN-u
   │
   ├── OpenMediaVault web admin ── nije direktno izložen internetu
   ├── Samba / SMB shareovi ────── nisu direktno izloženi internetu
   ├── disk 1 ── BLACK
   ├── disk 2 ── BLUE
   └── systemd / hookovi / SMTP obavijesti

Bitna odluka u dizajnu je da se SMB i OMV admin ne objavljuju izravno na internetu. Izvana je dostupan VPN endpoint; nakon uspješne VPN autentikacije klijent dobiva put prema privatnoj mreži i tek tada pristupa serveru kao lokalnom uređaju. Time se broj javno izloženih servisa smanjuje na minimum.

NAT i port forwarding

Kućni uređaji koriste privatne IP adrese koje internet sam po sebi ne routa. Router radi NAT — Network Address Translation — i prema internetu predstavlja cijelu lokalnu mrežu jednom javnom adresom. Dolazni paket s interneta zato ne zna automatski kojem lokalnom uređaju pripada.

Port forwarding dodaje eksplicitno pravilo: promet za odabrani VPN UDP port prosljeđuje se Raspberry Piju. To pravilo ne znači da je cijeli Pi „otvoren internetu”; javno je dostupan samo servis koji sluša na proslijeđenom portu.

što OpenVPN zapravo radi

OpenVPN između klijenta i Raspberry Pija uspostavlja autentificirani i šifrirani tunel. Operacijski sustav dobije virtualni mrežni interfejs, a IP paketi namijenjeni kućnoj mreži ulaze u taj virtualni interfejs, kriptiraju se, šalju kroz internet i na VPN serveru ponovno izlaze kao normalan mrežni promet.

laptop / mobitel
   │
   │  privatni IP paket: "želim 192.168.x.x"
   ▼
virtualni VPN interfejs
   │
   │  enkripcija + autentikacija
   ▼
internet
   │
   ▼
OpenVPN na Raspberry Piju
   │
   │  dekripcija
   ▼
kućni LAN / OMV / Samba

To je važna razlika u odnosu na običan web login: VPN ne štiti samo jednu stranicu nego stvara privatni mrežni put kroz koji mogu prolaziti različiti protokoli.

OpenMediaVault: upravljački sloj, ne filesystem sam po sebi

OpenMediaVault daje web sučelje za administraciju Linux storagea: diskove, mountove, korisnike, shared foldere, dozvole i servise. Pod njim i dalje postoje normalni Linux filesystemi i Linux permission model. OMV zato nije „poseban tip diska”; on organizira i konfigurira postojeće Linux storage komponente.

Samba / SMB: kako Windows vidi Linux disk kao mrežni share

Samba implementira SMB protokol na Linuxu. Kada Windows otvori mrežni share, on ne čita ext4 ili drugi Linux filesystem izravno. Windows šalje SMB zahtjeve serveru, Samba ih prevodi u filesystem operacije na Linuxu, a zatim rezultat vraća klijentu kroz mrežu.

Zbog toga postoje najmanje dva sloja dozvola: Samba pravila i stvarne Linux dozvole nad direktorijem. Ako jedan sloj dopušta pristup, a drugi ga blokira, korisnik svejedno neće moći otvoriti podatke.

HTTPS na OMV-u i zašto browser može reći „nije sigurno” iako je promet šifriran

HTTPS daje TLS enkripciju između browsera i OMV web servera. Kod self-signed certifikata enkripcija može biti potpuno stvarna, ali browser nema javni Certificate Authority kojem vjeruje i koji jamči da je taj certifikat stvarno izdao baš tvoj server.

Zato upozorenje browsera u tom slučaju najčešće znači „identitet certifikata nije potvrđen kroz moj trust store”, a ne automatski „promet ide plaintextom”. Ako certifikat ručno vjeruješ na svom uređaju ili koristiš vlastiti lokalni CA, warning se može ukloniti bez izlaganja admin sučelja javnom internetu.

zašto VPN + HTTPS zajedno imaju smisla

VPN i HTTPS nisu duplikat iste zaštite. VPN kontrolira tko uopće može doći do privatnog servisa i kojim mrežnim putem; HTTPS štiti konkretnu web sesiju i potvrđuje identitet servera kada je certifikat pravilno trusted. Obrambeni slojevi se zato nadopunjuju.

heartbeat sustava: systemd, hookovi i obavijesti

Na serveru se mogu vezati systemd servisi/timeri i OpenVPN hook skripte uz određene događaje: start/stop servisa, VPN connect/disconnect, periodične provjere ili druge administrativne događaje. Skripta zatim može zapisati event u log ili poslati e-mail kroz SMTP relay.

To daje jednostavan audit trail bez potrebe da stalno ručno gledaš server: ako se dogodi događaj koji si odlučio pratiti, server sam ostavlja trag ili šalje obavijest.

security model ovog setupa

  • minimalno izlaganje: javno je potreban samo VPN endpoint; SMB i OMV ostaju privatni.
  • enkripcija u tranzitu: udaljeni promet ide kroz VPN, a OMV web UI dodatno koristi HTTPS.
  • autentikacija: pristup VPN-u i pristup shareovima nisu ista vjerodajnica ni isti sloj.
  • least privilege: share korisnik treba samo prava koja stvarno koristi, ne nepotrebni admin pristup.
  • patching: sigurnost ovisi i o redovnom ažuriranju OS-a, OpenVPN-a, OMV-a i ostalih servisa.
  • backup: RAID, više diskova ili NAS sami po sebi nisu backup; važni podaci trebaju odvojenu kopiju.

homelab nije „siguran zato što je Raspberry Pi”. siguran je samo onoliko koliko su dobri mrežni dizajn, konfiguracija, credentiali, updateovi i backup strategija.

🎮 Retro konzola / Raspberry Pi 4 + RetroPie + 5" DSI

Retro konzola koristi Raspberry Pi 4, RetroPie/Raspberry Pi OS i mali 5-inčni DSI ekran. Cijela ideja je bila dobiti fizički uređaj koji radi samostalno na stolu, ali može po potrebi prijeći i na TV/HDMI izlaz.

compute: Raspberry Pi 4
frontend/emulation: RetroPie
lokalni display: 5" DSI ribbon ekran
vanjski display: HDMI / TV mode
kućište: vlastiti 3D print / TMNT tematika
veličina: otprilike „dvije jabuke”

DSI vs HDMI način rada

Jedan od konkretnih problema bio je kako zadržati mali DSI ekran, a istodobno omogućiti TV izlaz. Rješenje je bilo razmišljati o dva boot/config moda: konfiguracija optimizirana za DSI i konfiguracija za HDMI, uz jednostavne RetroPie menu skripte koje promijene config i rebootaju uređaj.

gamepad
   │
   ▼
Linux input subsystem
   │
   ▼
RetroPie / emulator
   │
   ├── DSI mode ── 5" ekran
   └── HDMI mode ─ TV / monitor

što emulator zapravo radi

ROM nije „pretvoren” u Raspberry Pi program. Emulator implementira ponašanje originalnog CPU-a, memorijskog mapiranja, grafičkog i audio hardvera dovoljno precizno da originalni binarni kod vidi okruženje slično stvarnoj konzoli. To je razlog zašto je emulacija kompromis između preciznosti, latencije i dostupne procesorske snage.

🤖 Mecanum line follower / Arduino Mega / encoder feedback

Robot je mecanum line follower s četiri zasebno pogonjena kotača, encoderima, IR line-sensor poljem i state machine logikom. Mecanum geometrija znači da nije ograničen na naprijed/natrag + rotaciju: pravilnim kombiniranjem brzina četiri kotača može raditi i bočni strafe.

kontroler: Arduino Mega
motor driver: Hiwonder 4-Ch Encoder, I²C 0x34
line sensor: Hiwonder 8-Ch IR, I²C 0x5D
motori: JGB37-520, 12 V, 110 RPM, 1:90
feedback: Hall AB encoderi
kotači: mecanum
display: LCD 20×4 I²C
napajanje: Einhell 18 V → buck 12 V

vanjska i unutarnja regulacija

Line follower radi kao hijerarhija. Vanjska petlja iz IR senzora računa položaj crte i generira korekciju smjera. Motor driver istodobno koristi encoder feedback za regulaciju brzine pojedinih motora. To je važno jer isti PWM ne znači nužno istu brzinu na četiri realna motora.

Zadnje korištene PID vrijednosti za line-follow korekciju bile su približno Kp = 0.26, Ki = 0.02, Kd = 0.18, uz BASE 24 i MAX 42. P dio reagira na trenutačnu pogrešku, I dio na akumulirani offset, a D dio na brzinu promjene pogreške.

state machine

FOLLOW_LINE
   ├── TURN_L_90
   ├── TURN_R_90
   ├── SEARCH_LINE
   ├── STRAFE
   ├── FRONT_BUMP
   ├── BACK_BUMP
   └── FULL_LINE_STOP

Za strafe su korišteni zasebni parametri, uključujući preload i ramp, jer idealna mecanum matematika ne zna za trenje, zazor, neravnomjeran pritisak kotača i inerciju stvarnog robota. Robot zato treba prijelaz, a ne samo trenutačno postaviti teorijski vektor.

i da: motor driver je kroz razvoj pregorio više puta. to je isto dio dokumentacije.

⚡ „ozonator” / 18650 + impulsni HV generator

Projekt je koristio tipični mali modul koji se prodaje kao „DC 3–6 V → 400 kV pulse generator”. Marketinšku brojku „400 kV” ne treba tretirati kao kalibrirano mjerenje stvarnog izlaza. Takvi moduli daju visokonaponske impulse, a stvarni napon i energija ovise o topologiji modula, napajanju, opterećenju, razmaku i geometriji elektroda.

ćelija: XTAR INR18650, 2600 mAh, 1S Li-ion
napon ćelije: oko 3.6–3.7 V nominalno, 4.2 V puna
BMS: 1S common-port, 15 A
punjenje: USB-C TP4056, 1 A
HV modul: 3–6 V impulsni generator
LV wiring: 18 AWG
konektor: XT30

što impulsni HV modul radi u principu

Niski DC napon najprije se elektronički prekida velikom frekvencijom. Promjenjiva struja može zatim pobuditi transformator s velikim omjerom namota, nakon čega ovisno o konkretnoj izvedbi slijedi visokonaponsko ispravljanje i/ili multiplikacija. Ključ je da transformator ne može povisiti savršeno konstantan DC; treba mu promjenjivi magnetski tok, pa elektronika na ulazu DC najprije pretvara u pulsirajući signal.

zašto nastaje korona i ozon

Jako električno polje može ubrzati slobodne elektrone dovoljno da sudarima pobude, ioniziraju ili disociraju molekule plina. U zraku dio procesa može disocirati molekularni kisik:

e⁻ + O₂ → e⁻ + O + O

Slobodni O zatim može sudjelovati u tro-tjelesnoj reakciji u kojoj treća čestica M odnese višak energije:

O + O₂ + M → O₃ + M

Oštar vrh elektrode koncentrira električno polje, pa se djelomični izboj može pojaviti lokalno prije nego što cijeli razmak prijeđe u veliki luk. Korona i potpuni električni luk nisu ista stvar. Luk snažno zagrijava kanal plina; više vidljive iskre ne znači automatski više korisno proizvedenog ozona.

sigurnosna napomena: ovo je opis fizike i konkretnog starog projekta, ne uputa za povećavanje izlaza. Impulsni HV moduli mogu dati bolan ili opasan udar, Li-ion ćelije nose vlastiti rizik, a ozon je respiratorni iritans. EPA navodi da ozon pri koncentracijama koje su sigurne za ljude općenito nije učinkovit univerzalni „air cleaner”, a veće koncentracije mogu oštetiti pluća.

🖨 3D print / Ender 3 S1 Pro / funkcionalni dijelovi

Printer je Ender 3 S1 Pro. Većina praktičnih dijelova bila je PLA, uz pokušaje s ABS+. Projekti su uključivali kućište retro konzole, NAS nosače, Hoover mount i druge funkcionalne dijelove.

što FDM zapravo radi

Fused Deposition Modeling gradi objekt sloj po sloj. Filament se mehanički gura kroz zagrijanu zonu, polimer omekša ili se rastali, mlaznica položi trag materijala i taj se trag spoji s prethodnim slojem. Rezultat zato ima anizotropiju: čvrstoća u ravnini sloja i između slojeva nije nužno ista.

zašto „dimenzija u CAD-u” nije automatski „dimenzija iz printera”

Na stvarni fit utječu širina ekstruzije, hlađenje, skupljanje polimera, tolerancije osi, first-layer squish i geometrija featurea. Zato rupa promjera 5.00 mm u CAD-u ne mora izaći kao savršeno 5.00 mm. Funkcionalni print traži dizajniranu toleranciju, a ne samo lijep model.
